# Contribiuting to pckg
Thanks for your interest in improving pckg
fixing spelling mistakes, updating readme.md, fixing bugs, adding new features. Your help is welcome, even the smallest one.


# Project structure.
This project is quite simple. and only needs 2 files to run:
- main.lua ( core of the project containing all functions )
- run.lua ( an cli interface for pckg )

install.lua is exists only to make installation easy.

# How to contribute
1. Click the fork button on github, clone the fork and create new branch
```bash
git clone < your fork url >
cd Package-manager-CC-T
```

1. After youre done, push your changes into fork and create pull request
